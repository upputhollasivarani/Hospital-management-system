# 🏥 Hospital Management System
https://github.com/upputhollasivarani/Hospital-management-system
## 📌 Project Overview

The **Hospital Management System** is a web-based application developed to manage hospital patient records efficiently. It allows users to add, view, search, update, and delete patient information through a simple and user-friendly dashboard.

This project is developed using HTML, CSS, and JavaScript.

## 🚀 Features

- Add new patient details
- View patient records
- Search patients by name
- Edit existing patient information
- Delete patient records
- Store patient data using Browser Local Storage
- Responsive user interface

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Webpage structure |
| CSS3 | Styling and responsive design |
| JavaScript | Application functionality |
| Local Storage | Storing patient records |

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Extract the project folder.
3. Open the folder in Visual Studio Code.
4. Open `index.html` in your browser.
5. You can also use the Live Server extension in VS Code.

## 💻 Application Modules

### 1. Add Patient
Enter patient details such as name, age, gender, phone number, disease, and date.

### 2. View Patient Records
Display all registered patient information in a table.

### 3. Search Patient
Search for patient records using the patient's name.

### 4. Update Patient
Edit and update existing patient information.

### 5. Delete Patient
Remove patient records from the application.

## 🎯 Project Objective

The main objective of this project is to simplify patient record management and demonstrate practical knowledge of frontend web development, JavaScript DOM manipulation, and browser Local Storage.
